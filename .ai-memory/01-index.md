## 1. Repository Architecture Overview

This repository is the frontend user interface for LetsMarkNow:
- **Frontend Stack (`src/`):** React 19, TypeScript, Vite, Tailwind CSS, Lucide React, Radix UI.
- **Formal Specifications (`02-spec/`):** Coding standards, error handling, database guidelines, UI design system.
- **Canonical Prompts (`01-prompts/`):** Reusable execution workflows and reading protocols.
- **AI Agent Capabilities (`.agents/skills/`):** Antigravity skills (`read-memory-enhanced`, `parent-task-n-step-loop`).
- **AI Memory (`.ai-memory/`):** Long-term cognitive storage, active plans, issue logs.
